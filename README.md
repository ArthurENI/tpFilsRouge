## 🚀 Commencer à travailler
 
Cette section explique comment installer et utiliser une copie locale du projet.
 
Pour mettre en place une copie locale et la faire fonctionner, suivez les étapes ci-dessous.
 
### Conditions préalables
 
Voici un exemple des éléments nécessaires pour utiliser le projet.
 
* npm
 
```bash
npm install npm@latest -g
```
 
### Installation
 
1. Obtenez une clé API gratuite sur [Example.com](https://example.com).
 
2. Clonez le dépôt :
 
```bash
git clone https://github.com/thierry-laval/P22-template-pour-unreadme.git
```
 
3. Accédez au dossier du projet :
 
```bash
cd P22-template-pour-unreadme
```
 
4. Installez les dépendances :
 
```bash
npm install
```
 
5. Ajoutez votre clé API dans `config.js` :
 
```javascript
const API_KEY = 'VOTRE_CLÉ_API';
```
